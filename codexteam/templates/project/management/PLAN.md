# Team Execution Plan

Execute tasks in `TASKS.md` order. T001 configures `management/TEST_GATES.toml`, names architecture and commit boundaries, and finalizes requirements. The Architect produces the accepted structure before implementation. The Developer proves algorithms/components and smoke behavior with the Development Gate; the Test Engineer owns the CI-equivalent Integration Gate and may change only its scoped tests and expectations with requirement-backed justification. Each task worker reads the matching handoff, writes only within allowed paths, and returns a schema-valid result under `results/`. The Reviewer audits architecture conformance, source, tests, gate composition, and evidence before the leader advances state. A Local Git Steward may prepare one local commit only after the Project Lead marks a milestone commit-ready.

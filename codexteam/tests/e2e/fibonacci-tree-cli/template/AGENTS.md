# Fibonacci Tree CLI Agent Rules

Read `BRIEF.md`, `PROJECT.md`, `CURRENT_TASK.md`, and the active handoff before acting.

- Keep every write inside this project root.
- Treat `PROJECT.md` and the active handoff as authoritative scope.
- A draft is conversational work for Project Lead review, not a final result or state transition.
- Use the same responsible AI session and attempt for finalization.
- Do not create one-off audit, patch, or verification scripts.
- Do not modify canonical task or project state; the Project Lead closes verified work.
- Report routine uncertainty to the Project Lead. Escalate only a genuine showstopper.

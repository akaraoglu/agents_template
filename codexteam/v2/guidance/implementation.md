# Implementation

## Purpose
Implement the approved design with the smallest coherent production and producer-test change.

## Workflow
Inspect relevant contracts, edit only assignment scope, preserve unrelated behavior, and report exact changes and evidence.

## Validation
Run focused developer checks, inspect the diff, and ensure changed behavior has practical regression coverage.

## Stop And Escalate
Stop for out-of-scope writes, destructive actions, credentials, unresolved design, or checks that cannot be run safely.

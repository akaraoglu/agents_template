# Verification

## Purpose
Independently test the current candidate against approved acceptance criteria.

## Workflow
Bind checks to the candidate and workspace, run focused then integration checks, classify failures, and preserve exact evidence.

## Validation
Require criterion-level results, fresh command evidence, and a clean audit of test-only changes.

## Stop And Escalate
Stop for stale identity, product defects, unsafe commands, environment failure, or any required criterion that cannot be evaluated.

# UX Design

## Purpose
Define an implementation-ready interface that fits approved requirements and architecture.

## Workflow
Describe user flows, states, responsive behavior, accessibility expectations, and bounded design artifacts. Do not edit production code.

## Validation
Check all interaction states, keyboard and assistive use, narrow and wide layouts, and acceptance-criterion traceability.

## Stop And Escalate
Stop for unresolved product behavior, inaccessible requirements, scope expansion, or architecture conflicts.

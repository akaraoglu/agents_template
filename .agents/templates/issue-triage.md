# Issue Triage

## Summary

Briefly describe the defect or request and affected user outcome.

## Impact and Priority

- Severity and likelihood
- Affected users, systems, versions, or environments
- Regression status and known workaround

## Expected Behavior

State what should happen and the source of that expectation.

## Observed Behavior

State what happens instead, including exact errors or incorrect output.

## Reproduction

1. Preconditions and environment
2. Minimal steps or command
3. Observable result

## Scope

- Affected components and interfaces
- Known unaffected areas
- Suspected change or trigger, clearly labeled as a hypothesis

## Evidence

- Logs, traces, screenshots, failing tests, metrics, or links
- Redactions or evidence limitations

## Acceptance Criteria

- Conditions that prove resolution
- Regression and compatibility checks

## Next Action

State the owner, immediate discriminating investigation or implementation step,
and any decision or authorization required.
